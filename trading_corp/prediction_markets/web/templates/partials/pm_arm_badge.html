{# Read-only ARM badge -- rendered from the PERSISTED agent_state row (arm.read_display), never a fail-safe collapse. `state` is one of armed / disarmed / absent / unavailable. Each is its OWN state: armed -- persisted row says armed. disarmed -- persisted row EXISTS and says off. absent -- NO row was ever written: 'NEVER ARMED' (no ts, so no age chip). Distinct from disarmed. unavailable -- an indeterminate mode=ro read (e.g. near a restart); shown as its own state, NEVER a disarm. `age` is the row's own write-timestamp age (a chip like every other feed value); absent carries no ts so no chip is drawn. It is a plain with NO control: pm_web can never arm/disarm; the CLI is authoritative. #} {% macro arm_badge(state, age, prefix='') -%} {%- set cls = 'armed' if state == 'armed' else ('unavailable' if state == 'unavailable' else ('never' if state == 'absent' else 'disarmed')) -%} {{ prefix }}{% if state == 'armed' %}ARMED{% elif state == 'unavailable' %}STATE UNAVAILABLE{% elif state == 'absent' %}NEVER ARMED{% else %}DISARMED{% endif %}{% if age is not none and state != 'absent' %} {{ age|agefmt }}{% endif %} {%- endmacro %}
